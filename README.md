## 🚀 Quick Start

### 1. Run in Development Mode
```bash
git clone https://github.com/zupeirupdi/zupeir-portfolio.git
cd zupeir-portfolio
npm install
npm run dev
```

### 2. Build for Production & Standalone HTML
```bash
npm run build
```
This builds the production bundle in `dist/` and automatically updates `portfolio-single.html`.

### 3. Open Standalone Version
Simply double-click `portfolio-single.html` in your browser. No Node.js or server required!
